Rendering Obj Files using OpenGL 2023-03-17

Summary

C++와 OpenGL을 기반으로 3D 모델 로딩 및 실시간 렌더링을 구현한 과제입니다. Assimp를 활용해 OBJ 모델을 로딩하고 Vertex/Fragment Shader를 통해 모델과 바닥을 렌더링했으며, WASD 및 마우스 입력을 기반으로 카메라의 위치와 시점을 자유롭게 변경하는 기능을 구현했습니다. 또한 ImGui를 연동하여 모델의 Scale과 Color를 런타임에 조절할 수 있도록 구성했습니다.
