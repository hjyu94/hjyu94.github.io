Rendering Obj Files using OpenGL 2023-03-17

과제

LearnOpenGL 참고(3.model_loading, assimp)로 제공된 OBJ를 렌더링하고, 시점을 자유롭게 변경할 수 있게 하기. GUI 추가 시 가산점(ImGui).

참고/기존 파일

LearnOpenGL의 model loading 예제 구조 — Model, Mesh, Shader 클래스, assimp로 OBJ 로드·렌더링.

아래는 그 위에 본인이 추가·구현한 부분만 정리한 것.

1. 자유 시점 변경 (change viewpoint freely)

  • WASD: processInput()에서 cameraPos를 cameraFront·cameraUp·우측 벡터 기준으로 이동. 전후좌우 자유 이동.
  • 마우스 드래그: 왼쪽 버튼 누른 상태에서 이동 시 mouse_callback()에서 yaw, pitch 갱신 후 cameraFront 재계산 → 시선 방향 변경.
  • 드래그 활성화: mouse_button_callback()에서 좌클릭 press/release 시 lButtonClicked 플래그로 "지금 드래그 중인지" 구분.
  • UI와 분리: ImGui 창 위에 마우스가 있거나(isMouseHoverUi) 컬러 편집 중(isColorChanging)일 때는 mouse_callback에서 early return 해서, GUI 조작 시 카메라가 돌아가지 않도록 처리.

→ 과제 목표인 "change the viewpoint freely"를 위 방식으로 구현한 부분.

2. GUI (ImGui, 가산점 대응)

  • 초기화: ImGui::CreateContext(), ImGui_ImplGlfw_InitForOpenGL, ImGui_ImplOpenGL3_Init, ImGui::StyleColorsDark(), 매 프레임 NewFrame / Render / ImGui_ImplOpenGL3_RenderDrawData.
  • Bunny Interface 창:
    • ImGui::SliderFloat("Size", &bunny_size, 0.f, 3.f) → 오브젝트 스케일 조절.
    • ImGui::ColorEdit3("Color", ...) → 오브젝트 색상 변경.
    • ImGui::Text("Use WASD and left mouse button to change the viewpoint.") → 조작 안내.
  • 렌더 반영: 모델 행렬에 bunny_size 스케일 적용, 셰이더에 bunny_color를 ObjColor로 전달해 화면에 반영.

→ 과제의 "Adding a proper GUI will get extra credit. ImGui is a good starting point."에 맞춘 구현.

3. 장면 구성 및 프로젝트 통합

  • 이중 장면: (1) 바닥 — 별도 셰이더(floor_shader.vs/fs), 텍스처(wood.png), 큰 스케일 평면. (2) OBJ 모델 — model_loading.vs/fs, assimp로 로드한 OBJ. 한 루프 안에서 둘 다 그리기.
  • OBJ 파일 지정: argv[1]로 실행 인자 받아 CURRENT_SOURCE_DIR + "/model/" + objectFileName 경로로 Model 생성. 제공된 여러 OBJ 중 어떤 걸 쓸지 실행 시 선택.
  • 리소스 경로: CMake CURRENT_SOURCE_DIR로 HW1 소스 디렉터리 고정, 그 아래 shader/, model/, texture/ 사용 (실행 파일 위치와 무관하게 동일 경로 사용).

참고 예제는 "모델 하나" 위주인데, 바닥+모델, 명령줄 인자로 OBJ 선택, 과제 디렉터리 구조에 맞는 경로를 넣은 부분.
